# KVFold demonstration paper

[**kvfold-demo/**](kvfold-demo/README.md) is the standalone manuscript package.
Copy that directory to edit or build the paper on another machine. It contains
the [four-page PDF](kvfold-demo/kvfold_1127.pdf), LaTeX source, bibliography,
and figure assets. From the repository root, `make -C paper` rebuilds the PDF.

[evidence/](evidence/README.md) preserves the original experiment records and
their provenance. [materials/](materials/) holds author-supplied manuscripts
and figure references cited by those records. Local reading copies and
editorial notes may also be kept in `materials/local/`.
