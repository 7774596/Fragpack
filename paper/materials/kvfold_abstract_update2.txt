Abstract

LLM agents often reuse long prompt prefixes when continuing tasks or resuming sessions. Caching the corresponding key/value (KV) states avoids repeated prefill, but limited cache capacity constrains request concurrency and history retention. We present KVFold, a lossless KV-cache compression system that uses high-byte coding to expand GPU and external-cache capacity while preserving the original BF16 bits. Pool mode stores compressed KV on the GPU and reconstructs values for attention. Tier mode compresses KV in LMCache while retaining the native GPU cache layout and attention implementation. In recorded AgentX runs with a fixed 54 GiB KV budget per GPU, pool mode increases usable capacity from 1.18M to 1.59M tokens. Interactive tasks illustrate prefix reuse, while recorded workloads show how added capacity improves history retention and reduces time to first token under constrained cache budgets.
