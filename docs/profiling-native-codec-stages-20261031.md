# Native codec 阶段 profiling（2026-10-31）

当前大批量恢复的主要耗时在 GPU 解码与 native 页写回；目标页冲突检查不是优先瓶颈。N=256 时，独立解码阶段约 7.06–7.15 ms，完整恢复约 7.56–7.72 ms。[工作区拆分和有界复用](optimization-native-codec-memory-20261031.md)已完成，下一步对合并写回的候选 kernel 做独立 A/B；本次不支持优先重写别名扫描。

在同一张 GPU 2（H800 PCIe，UUID `fb9880e5-6155-b080-837a-948d5fd08b4c`）上运行两个独立进程，第二次反转操作起始顺序。环境为 PyTorch 2.13.0+cu129、vLLM 0.30.0+cu129。每项预热 3 次、正式采样 24 次，共 3,456 条样本。两轮源代码、输入、码表及对应配置的 KV/query hashes 一致。

负载为 48 层、BF16 KV、GQA 32:4、D=128、Q=128。N 是 128-token 逻辑块数，P 是 native 页的 token 数，覆盖 2,048 与 32,768 token。数据来自已有 Qwen3-30B-A3B/OpenHands CPU 捕获：FP8 模型权重解量化为 BF16 后产生的 BF16 KV，不能称作 FP8 KV。校准位置 0:8、评估池 8:32；N=256 重复该评估池，query 独立随机生成。本实验从已在 GPU 的 FPKB 开始，只测恢复和只读 attention，不含 H2D、模型计算、新 KV 写入或 serving。

别名检查使用真实 `validate_mapping` kernel 的开关对照：两臂均检查范围，仅诊断臂省略重复页检查。该臂只输出 status，不用于不安全的恢复。下列差值是两臂中位数之差，单位 µs：

| 16 | 16 | 4.672 / 4.608 | 8.288 / 8.288 | 3.616 / 3.680 | 0.794% / 0.813% |
| 16 | 128 | 4.384 / 4.560 | 5.024 / 4.800 | 0.640 / 0.240 | 0.143% / 0.054% |
| 256 | 16 | 5.008 / 4.928 | 62.960 / 62.848 | 57.952 / 57.920 | 0.752% / 0.751% |
| 256 | 128 | 4.640 / 4.528 | 11.680 / 11.856 | 7.040 / 7.328 | 0.093% / 0.097% |

N=256、P=16 的增量约 58 µs，相对完整恢复不到 0.8%；P=128 约 7 µs，不到 0.1%。最后一列是假设该增量能完全消除且没有新增成本的乐观诊断估算，不是实测完整路径加速或严格上界。头部阶段本来就包含映射检查，不应重复计入这部分时间。

接口成本另看 eager 的 host enqueue 时间：它计入调用、参数检查、status 清零提交等，不含完成等待，不能直接当作纯 Python 开销。下表单位 µs：

| N | P | 公开 codec 提交 | 直接 C++ 扩展提交 | 两者差值 |
|---:|---:|---:|---:|---:|
| 16 | 16 | 44.10 / 41.42 | 10.45 / 9.52 | 33.65 / 31.90 |
| 16 | 128 | 44.18 / 40.80 | 10.22 / 10.13 | 33.96 / 30.67 |
| 256 | 16 | 45.28 / 42.30 | 10.63 / 9.78 | 34.65 / 32.52 |
| 256 | 128 | 46.21 / 42.17 | 10.64 / 10.66 | 35.57 / 31.51 |

公开接口的额外 host 提交量级约 31–36 µs，尤其值得在小 chunk、频繁调用时观察。Graph 中公开与直接扩展恢复的差值为 −23.856 至 +0.384 µs，属于不同捕获路径下的小幅差异；它没有测量 Python 执行，不能解释为“负接口开销”。eager 的 GPU event span 还可能包含 CPU 提交导致的空隙，不能当作纯 kernel 时长。本报告依据 CUDA events，未将 Nsight 跟踪或硬件计数作为证据。

所有配置均通过恢复前填毒后的完整 KV 逐位校验、未选中页检查、FA3 输出逐位比较及重复页/负页号/越界页号拒绝检查。两轮 payload 中均无 raw fallback，因此这份阶段结论不覆盖高 fallback 输入。
