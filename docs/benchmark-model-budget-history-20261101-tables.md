# 完整历史工作集回放结果

KV预算 44.662192128 GB；每会话 32,768 tokens；每条trace 128请求；每个case的F/R各6轮。总计672条计时trace、86,016请求。

所有F/R数字按正序进程/反序进程排列，时间为各自完整trace wall中位数。复用命中率排除前W次必然冷启动；命中表示整会话在GPU HBM中。历史KV来自重复/旋转的既有BF16捕获；模型仅独立测预算，计时期间不驻留。这是48层缓存恢复和attention读取回放，不是完整模型serving。

纳入分析的执行进程共3个：F占2个，R占1个。每个case恰有一次F和一次R；若F分段，完整前缀沿用原进程，剩余case在新进程中保持原顺序。没有将两段算作额外重复。

## 解释边界

- F/R分开报告，轮次是同一进程内重复，不计算伪独立置信区间。
- 若采用预声明的F分段，重启改变allocator、热状态和轮间写盘间隔；原进程running/-15保留，只有完整case纳入。
- 完整wall包含policy、实际H2D、恢复和attention读取；不含历史准备/编码、模型MLP或服务排队。
- 外部host历史全部保留，此处不是外部缓存命中率或受限DRAM容量实验。
- 部分中止/失败尝试未混入，详见审计记录：history-main-r1、history-main-r2、history-main-r4、history-main-r5。
- H2D payload和metadata、逐方向容量、恢复/读取分项及所有pair比较保留在compact JSON。
